# Menu photographs

Put one photograph per menu item here, named exactly as below (WebP, about 1200 px square, transparent or white background, no watermark).
Then open `bunbun/menu.js` and add `photo: '<file name>'` to that item. Any item without a `photo` keeps its 3D picture.

Photographs must be your own or properly licensed for commercial use. Watermarked stock photos must not be used.
